# Career Mind Map ![favicon](public/careermindmap.svg)

Live at: https://alpinemily.github.io/career-mind-map/

Inspired by the book _Designing Your Life_, mind maps are a tool for expanding possibilities before narrowing them down. Instead of asking "What job should I get?", start with themes and branch into related ideas, applying lateral thinking to find new connections and alternate life directions.
